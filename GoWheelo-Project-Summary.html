Project Summary

GoWheelo

Premium peer-to-peer car rental platform built on the MERN stack

React 18 Node.js Express MongoDB Socket.io Tailwind CSS

1. What this project is

GoWheelo is a premium peer-to-peer car rental app where a vehicle owner can list a car, and a customer can view, book, and chat with the owner before renting. It combines rental booking workflow, OTP-based authentication, live messaging, and a polished premium UI to simulate a real-world marketplace experience.

“This is not just a booking app — it is a full digital rental marketplace with trust, communication, and payment simulation built in.”

2. Core features implemented

Secure Authentication

  • Signup with email verification and 6-digit OTP
  • Password hashing using bcrypt
  • JWT-based authentication with cookie-based session

Live Communication

  • Real-time chat between renter and host
  • Socket.io rooms for conversation-based messaging
  • WebSocket transport optimization for reconnection stability

Booking & Availability

  • Booking system with date-based search and car details
  • Collision detection to prevent overlapping bookings
  • Host can accept or reject booking requests

Owner Dashboard

  • Add new cars to inventory
  • View current bookings and manage them
  • Delete listings safely through database-safe delete logic

Payments & Checkout Simulation

  • Hybrid checkout panel with payment inputs
  • UPI QR code generation using qrcode.react
  • Currency conversion logic for USD/INR display

Premium Frontend UX

  • Glassmorphism aesthetic and dark/light theme
  • Responsive layout for desktop and mobile
  • Animations via Framer Motion and GSAP

3. Tech stack used

Frontend

  • React 18 + Vite
  • React Router DOM for client-side routing
  • Tailwind CSS for modern styling
  • Axios for HTTP requests
  • Framer Motion + GSAP for interactive UI motions
  • Socket.io Client for real-time messaging
  • qrcode.react for dynamic QR code generation

Backend

  • Node.js with Express.js
  • MongoDB with Mongoose ODM
  • Socket.io server for chat events
  • JWT for auth tokens
  • bcrypt for password security
  • Brevo REST API for OTP mail delivery

4. Architecture and how it works

The frontend is built as a single-page React application using route-based pages such as Home, Cars, CarDetails, MyBookings, and BecomeAHost. Shared state and app-level configuration are managed in AppContext, while theme settings are controlled in ThemeContext. This makes the application feel like a modern marketplace UI with a smooth user journey.

The backend runs Express APIs for authentication, vehicle operations, booking management, and payment simulation. MongoDB stores user profiles, cars, and booked slots. Real-time events are powered by Socket.io so renters and owners can communicate instantly without page refresh. Important validations happen on the server side to ensure date conflicts, secure access, and token-based authorization.

5. Real-world engineering decisions and problem-solving

  • Email delivery challenge: SMTP ports were blocked on hosting platforms, so Brevo’s secure HTTP API was used instead of traditional SMTP.
  • Realtime chat reliability: Socket.io was configured to use websocket transport only for more stable live communication.
  • Booking conflict prevention: Logic ensured no overlapping dates for the same vehicle.
  • Modern Mongoose compatibility: Deprecated .remove() was replaced with safe query methods such as findByIdAndDelete.
  • SPA routing on Netlify: Added a _redirects file to route all frontend paths back to index.html.
